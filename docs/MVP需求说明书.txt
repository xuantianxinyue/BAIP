本地 RAW AI 批处理修图工具 MVP 需求说明书
一、项目概述
1.1 产品定位
一款纯离线、轻量级 macOS 原生工具，面向人像 / 风光独立摄影师，在导入 Lightroom 前完成批量 AI 降噪、人像基础精修预处理。主打「小体积、纯本地、买断制、隐私安全」，替代重型付费修图软件的前置处理环节。
1.2 目标硬件
	•	最低适配：MacBook Air M1 2020（8GB 内存 + 256GB 硬盘）
	•	优化重点：充分调用 M1 神经引擎，控制内存占用，保证 8GB 内存设备流畅运行

1.4 硬性能指标（必须达标）
	•	单张 2400 万像素 RAW 图片 AI 降噪耗时 ≤ 8 秒
	•	应用运行峰值内存占用 ≤ 6GB
	•	安装包体积 ≤ 500MB
	•	连续批量处理 50 张 RAW 图片无崩溃、无内存泄漏
	•	所有功能 100% 离线运行，无任何网络请求、无数据上传、无埋点
二、功能范围（MoSCoW 优先级）
2.1 Must Have（MVP 必须实现）
	•	文件批量导入：支持文件夹批量导入，兼容 CR2/NEF/ARW/RAF/DNG 等主流 RAW 格式 + JPG 格式
	•	缩略图与 EXIF 展示：导入后生成缩略图列表，显示光圈、快门、ISO、相机型号、拍摄时间
	•	AI 通用降噪：适配高 ISO 风光、弱光人像，保留画面细节，无明显涂抹感
	•	人像轻量精修：自动识别人脸，完成自然磨皮、去除明显痘印瑕疵，不假面、不糊五官
	•	前后对比预览：单张图片支持左右分屏 / 点击切换对比处理前后效果
	•	批量处理队列：多选照片统一配置处理项，后台队列串行执行，支持暂停 / 取消
	•	结果导出：支持导出 JPG（可调质量）/ DNG 格式，保留完整 EXIF，不覆盖原图，可指定输出目录
2.2 Should Have（MVP 不做，后续迭代）
	•	基础调色预设批量套用
	•	天空替换功能
	•	Lightroom 插件联动
	•	批量重命名、分类归档
2.3 Won’t Have（MVP 绝对禁止开发）
	•	专业调色面板、曲线、HSL、色阶等完整显影功能
	•	物体移除、背景替换等生成式重绘功能
	•	AI 内容打标、语义图片检索
	•	用户账号系统、云端同步、数据统计埋点
	•	精细化人脸参数微调面板（磨皮力度、瘦脸、美白等）
	•	Windows 版本、移动端版本
三、核心模块详细需求
3.1 文件导入与管理模块
	•	支持拖拽文件夹 / 文件到窗口导入，支持系统文件选择面板
	•	导入后自动去重，重复文件提示跳过
	•	列表支持多选、全选、取消选择
	•	错误提示：不支持的格式、损坏文件单独标记，不中断整体导入流程
3.2 缩略图与 EXIF 模块
	•	缩略图缓存机制，二次导入同文件夹无需重新生成
	•	鼠标悬浮 / 选中时显示完整 EXIF 信息：相机型号、镜头、焦距、光圈、快门、ISO、拍摄时间
	•	列表支持按拍摄时间、文件名排序
3.3 AI 降噪模块
	•	模型：基于 MLX 优化的 4bit 量化 Real-ESRGAN 轻量化版本
	•	强度档位：低 / 中 / 高三档，默认中档
	•	处理逻辑：保留边缘细节，避免文字、建筑边缘模糊
	•	异常处理：无法识别的图片自动跳过，记录错误日志
3.4 人像轻修模块
	•	自动检测画面中的人脸，支持多人脸同时处理
	•	核心能力：自然磨皮、去除明显痘印 / 斑点、均匀肤色
	•	约束：不改变人脸轮廓、不磨掉五官细节，效果自然不假面
	•	无人脸的图片自动跳过该模块，仅执行降噪
3.5 前后对比模块
	•	两种对比模式：左右分屏对比、点击按住切换对比
	•	支持缩放查看细节，缩放时同步移动前后画面
	•	仅对已处理完成的图片可用，未处理的提示「先执行处理」
3.6 批量队列模块
	•	队列可视化：显示当前处理进度、已完成数量、剩余数量、单张耗时
	•	支持暂停、继续、取消当前任务
	•	后台运行：窗口最小化后继续处理，完成后系统通知提醒
	•	错误容错：单张处理失败自动跳过，继续处理下一张，最终输出失败清单
3.7 导出模块
	•	导出格式：JPG（质量 0-100 可调）、DNG（保留 RAW 信息）
	•	命名规则：保留原文件名，可选择添加后缀 _processed
	•	目录选择：可指定任意输出目录，默认在源文件同级新建 output 文件夹
	•	EXIF 保留：导出文件完整保留原始 EXIF 信息
