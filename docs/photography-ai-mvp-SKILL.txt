# 本地RAW AI批处理修图工具 MVP 开发规则
> 核心铁则：全程控制高级模型调用次数，SWE-1.5 能搞定的绝对不用高级模型；总高级调用不超过 17 次，剩余 8 次留作应急。

## 触发后执行流程
1. 先确认当前处于第几阶段，严格按顺序推进，上一阶段未通过验收，禁止进入下一阶段
2. 每个阶段内，优先使用免费模型完成 90% 以上代码编写与调试
3. 仅在下文明确标注的「可使用高级模型」场景，才能发起高级调用，且每次集中抛出 3-5 个关联问题一次性解决，禁止零散拆分提问
4. 每阶段完成后输出「阶段验收报告」，对照验收标准逐项自检，通过后再申请进入下一阶段

## 阶段划分与积分配额（强制执行）
### 第一阶段：环境搭建（第 1-3 天）
- 任务：初始化 Xcode 项目、集成 LibRaw、配置 MLX 开发环境、完成基础项目结构搭建
- 高级模型调用上限：1 次
  - 仅用于：一次性输出完整环境配置方案与依赖集成脚本
- 其余所有命令执行、依赖安装、报错排查，全部使用免费模型完成

### 第二阶段：核心逻辑开发（第 4-15 天）
- 任务：RAW 解析、AI 降噪、人像轻修、批量处理核心算法逻辑开发
- 高级模型调用上限：8 次
  - 仅可用于 3 类场景：
    1. M1 神经引擎加速适配疑难报错定位修复
    2. 批量处理内存溢出优化，流式加载逻辑生成
    3. 轻量化 4bit 模型本地推理逻辑全链路打通
- 所有单文件代码编写、基础函数实现、常规调试，全部使用免费模型完成

### 第三阶段：界面与交互开发（第 16-25 天）
- 任务：导入界面、缩略图列表、前后对比、进度条、导出设置界面开发
- 高级模型调用上限：6 次
  - 仅可用于：Mac 窗口适配、文件权限、沙盒机制等平台专属疑难问题
- 所有基础 UI 组件、布局、交互逻辑，全部使用免费模型完成

### 第四阶段：测试与交付（第 26-30 天）
- 任务：全流程测试、边缘问题修复、打包、生成使用说明
- 高级模型调用上限：3 次
  - 仅可用于：稀有 RAW 格式兼容修复、打包脚本生成、正式版使用文档输出
- 所有测试用例编写、常规 bug 修复、批量测试执行，全部使用免费模型完成

## 绝对不能浪费积分的 3 条红线（违反视为无效输出）
1. 禁止用高级模型写基础循环、判断、工具函数、简单 UI 布局，这类内容 SWE-1.5 完全可胜任
2. 禁止把一个完整需求拆成多次零散提问，每次集中抛出 3-5 个关联问题，一次性解决
3. 禁止用高级模型开发非 MVP 功能，包括但不限于：调色面板、天空替换、云端同步、用户体系、界面过度美化

## MVP 功能边界红线
✅ 必须做：批量导入、RAW 解析、AI 降噪、人像轻修、前后对比、批量队列、导出
❌ 绝对不能做：专业调色/HSL/曲线、天空替换、物体移除、AI 打标签检索、LR 插件、账号系统、云端功能

## 输出要求
- 所有代码必须可直接编译运行，适配 macOS 13.0+、M1 及以上苹果芯片原生运行
- 每阶段输出对应代码文件 + 阶段验收自检报告
- 所有性能指标必须量化，禁止「看起来不错」「效果尚可」这类主观表述
